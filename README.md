# PowerShellコマンド検索

PowerShellのよく使う基本コマンドを、コマンド名または「したいこと」から検索できるシンプルなWebアプリです。ビルド不要のプレーンなHTML/CSS/JavaScriptのみで作られており、GitHub Pagesでそのまま公開できます。スマートフォンでも利用できるレスポンシブデザインです。

## 機能

- **左右分割レイアウト**：左側に検索フォーム、右側に検索結果・一覧・詳細を常時表示します。
- **コマンド名で検索**：コマンド名（や `ls`, `dir`, `cat` などのエイリアス）を入力して検索。1件に絞れた場合は詳細画面へ直接移動し、複数当てはまる場合は候補リストを表示します。
- **したいことで検索**：「ファイルを削除したい」のような自然な言葉で検索。あらかじめ各コマンドに付与したキーワード（タグ）とのあいまい一致で候補を探します。
- **全コマンド一覧**：カテゴリ別（ファイル操作、プロセス管理、Active Directory、Hyper-Vなど36カテゴリ）にグループ化した一覧から探せます。
- **コマンド詳細画面**：コマンド名、主なパラメーター（引数）、使用例（各コマンド2件以上）を表示します。
- **検索リセット**：入力欄と右側パネルをまとめてクリアするボタンがあります。

## 使い方（ローカルで試す）

ビルドツールは不要です。以下のいずれかの方法で開けます。

- `index.html` をブラウザで直接ダブルクリックして開く
- もしくはローカルサーバーを立てて開く（推奨）
  ```
  cd pwsh-command-search
  python -m http.server 8080
  ```
  ブラウザで `http://localhost:8080` を開く

## フォルダ構成

```
pwsh-command-search/
├── index.html        … 画面のHTML（左：検索フォーム／右：検索結果・一覧・詳細をJSで切り替え）
├── styles.css         … スタイル（左右分割レイアウト、モバイル対応）
├── app.js             … 検索・画面遷移のロジック
├── data/
│   └── commands.js    … コマンドデータ本体（250件・36カテゴリ、Claudeが作成した静的データ）
└── README.md
```

## データについて

収録しているコマンド情報は、よく使われる基本的なPowerShellコマンドに加え、Active Directory・Hyper-V・BitLocker・タスクスケジューラなど管理者向けの周辺コマンドも含め、AI（Claude）がまとめた代表的な使い方の要約です（250件）。全パラメーターを網羅するものではなく、一部はRSAT/Hyper-Vなど別途モジュールが必要なコマンドも含まれます。正確な仕様が必要な場合は[Microsoft公式ドキュメント](https://learn.microsoft.com/powershell/)を参照してください。

コマンドを追加・修正したい場合は `data/commands.js` の配列に項目を追記するだけで反映されます（ビルド不要）。

## GitHub Pagesへの公開

このリポジトリは `main` ブランチのルートをそのままGitHub Pagesとして公開する設定になっています。`main` にpushするだけで自動的に反映されます。
